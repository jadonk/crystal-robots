Battle

  

    Two to four robots on the CROBOTS battlefield — the same physics and the same
    tree-walking interpreter bin/crystal-robots's own matches use, run entirely in
    this page. Pick from the bundled examples or paste your own for each slot, then press
    Run Battle. The replay draws the same shapes the served /battle page renders,
    but plays the match back live at 60 frames per second, with play/pause, an adjustable
    speed and a scrubber — every cannon shot and every hit lands on its own frame, however
    long the match runs.
